# facehub

Современный полноэкранный прототип персонального хаба для `дим-саныч.рф`. Главная и разделы работают как отдельные состояния без вертикального скролла.

## Что уже заложено
- светлая минималистичная визуальная система со стеклянными поверхностями;
- разделы: Книги, Музыка, Стихи, Блог;
- вход и регистрация;
- отдельное согласие на обработку персональных данных;
- админ-панель владельца `dimsan.kzn@gmail.com`;
- просмотр пользователей, блокировка/разблокировка;
- персональные дары доступа к скрытым материалам: отзывные и постоянные;
- добавление материалов только из панели владельца;
- подготовленный, но выключенный модуль монетизации через Т-Банк/онлайн-кассу;
- правовая страница с обязательными блоками и незаполненными реквизитами.

## Важно
`index.html` — основной интерактивный дизайн-прототип. `preview.html` оставлен как исходная копия текущего состояния. Авторизация и действия админки в нём демонстрационные и выполняются только в браузере. Нельзя использовать этот файл как production-систему для реальных персональных данных или платежей.

Для боевой версии нужно перенести интерфейс на серверное приложение с БД, серверной проверкой роли владельца, безопасным хранением паролей/сессий, журналом согласий и прав доступа.

## Рекомендованная production-архитектура
- Frontend: Next.js / React либо аналогичный SSR-фреймворк.
- Backend: серверные API того же приложения.
- БД: PostgreSQL.
- Авторизация: email + пароль/одноразовая ссылка, обязательная верификация email.
- Роль владельца: серверное правило для `dimsan.kzn@gmail.com` + отдельная запись роли в БД.
- Хранение файлов: S3-совместимое хранилище на инфраструктуре, подходящей под требования к локализации персональных данных.
- Аудит: журнал выдачи/отзыва доступа, блокировок, версий согласий.
- Платежи: адаптер Т-Банка; секреты только на сервере, модуль выключен до фактического подключения.

## Схема прав доступа
- `public` — материал виден всем;
- `restricted` — материал виден владельцу и пользователям с активным даром;
- `revocable_gift` — дар действует до ручного отзыва;
- `permanent_gift` — постоянный дар; интерфейс не предлагает отзыв, изменение требует отдельной административной процедуры.

## Персональные данные
Согласие хранится отдельно от регистрации: нужно сохранять текст/версию согласия, дату-время, пользователя и техническое подтверждение факта его получения. Политика обработки персональных данных размещается отдельной публичной страницей.

## Перед подключением Т-Банка
Заполнить реальными данными продавца: ФИО/наименование, ИНН, ОГРН/ОГРНИП, адрес, телефон, e-mail; разместить оферту, условия возврата и предоставления товара/цифрового контента, политику обработки персональных данных. Затем подключить интернет-эквайринг и совместимую облачную онлайн-кассу.
