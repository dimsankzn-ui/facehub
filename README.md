# facehub

Современный полноэкранный персональный хаб для проекта **«Дим Саныч»**.

Текущая версия — интерактивный статический прототип без вертикального скролла: главная и разделы работают как отдельные полноэкранные состояния.

## Структура

```text
facehub/
├── index.html\n├── auth.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       └── app.js
├── docs/
│   └── LEGAL_CHECKLIST.md
├── .gitignore
└── README.md
```

## Что реализовано

- светлый минималистичный интерфейс со стеклянными поверхностями;
- анимированные фоновые графические элементы;
- разделы «Книги», «Музыка», «Стихи», «Блог»;
- полноэкранная навигация без вертикальной прокрутки;
- отдельная страница авторизации и регистрации (`auth.html`);
- отдельное согласие на обработку персональных данных;
- демонстрационная панель владельца;
- управление пользователями и блокировкой;
- отзывные и постоянные персональные доступы;
- добавление материалов владельцем;
- заготовка под монетизацию через Т-Банк;
- правовые страницы и чек-лист подготовки.

## Локальный запуск

Проект не требует сборки. Можно открыть `index.html` напрямую или запустить простой локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.

## Важно

Авторизация, управление пользователями, права доступа и административные действия в текущей версии являются **демонстрационными** и выполняются в браузере.

Для рабочей версии нужны серверная авторизация, PostgreSQL, проверка роли владельца на сервере, аудит выдачи доступов, хранение фактов согласий и безопасная интеграция платежей.

## План дальнейшей разработки

1. Перенести интерфейс на React / Next.js или аналогичный стек.
2. Подключить PostgreSQL / Supabase.
3. Реализовать серверную авторизацию и RLS.
4. Добавить реальное управление контентом и файлами.
5. Подключить Т-Банк и онлайн-кассу только после заполнения юридических данных.
